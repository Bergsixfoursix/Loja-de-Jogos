Objetivo Geral 
Desenvolver um site, que simula uma loja de jogos eletrônicos on-line, com links direcionando a carrinho, pedidos e categoria de jogos. Integrando:
•	Controle de versão com participação individual comprovada via Git/GitHub;
•	HTML, CSS e JAVASCRIPT;

Regras de Negócio 
O projeto vai permitir o usuário navegar pelas categorias, por exemplo, catálogo de jogos mais vendidos, informações do produto, carrinho de produtos e simular uma compra.
